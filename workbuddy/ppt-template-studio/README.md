# WorkBuddy PPT Template Studio

这是 `ppt_creator-skills` 的 WorkBuddy 上传版。它让团队先把一份优秀 PPT 做成可点名的模板包，之后普通用户只用“模板包名 + 内容”即可生成同一风格的可编辑 PPT。

## 功能

- 从 PPTX/POTX 提取版式、字体、配色、页眉页脚、页码、图片、图标和文本容量，沉淀为可复用模板包。
- 让模板创建者按“保持／可变／每次确认”设置边界，而不是选择笼统的严格模式。
- 用模板包名称、主题或简要内容快速生成 PPT；大纲、页数、字数和边界均为可选补充。
- 没有模板包时，按业务目标、新媒体/调研/汇报等方向新建一份可编辑 PPT。

## 安装到 WorkBuddy

1. 下载或克隆本仓库。
2. 在 WorkBuddy 的“技能”页点击“添加技能” → “上传技能”。
3. 选择同级文件 `workbuddy/ppt-template-studio.zip` 作为本地技能包，并启用它；源目录 `workbuddy/ppt-template-studio` 也保留在仓库中，方便查看和修改。
4. 在要制作 PPT 的任务中启用 WorkBuddy 的 PPTX 办公文档能力。

## 建一次模板包

把原始 PPTX/POTX 放到当前任务工作区，然后直接说：

```text
把这份 PPTX 建成「市场调研·活力手账」模板包；以后按名称复用。
```

首次只需要补充原件、模板包名称和所有者。Skill 会提取页面样式与素材规则，并用一张确认卡确定默认大纲和保持／可变／每次确认的范围。

## 日常快速生成

```text
用「市场调研·活力手账」生成 PPT；内容：XR 直播间市场调研，面向内部领导。
```

需要临时调整时再加：

```text
页数：12；大框架：市场趋势、产品地图、技术路线、结论建议。
边界：字体、配色、页眉页脚保持；封面图和正文配图可变；允许新增两页。
```

## 模板库放哪里

模板包保存在当前 WorkBuddy 任务工作区，不随 Skill 上传。默认路径为：

```text
<工作区>/ppt-template-library/index.json
```

一个模板包包含原始 `original-template.pptx`、`package.json`、`profile.json` 和 `assets-manifest.json`。这让同一套模板可以由不同人点名调用，也能持续增加版本。

## 这个包的三个入口

| 你怎么说 | 它会做什么 |
| --- | --- |
| “把这份 PPTX 建成模板包” | 提取并登记可复用模板。 |
| “用「模板包名称」生成 PPT” | 读取模板包默认设置，快速填充内容。 |
| “做一份 XX 汇报 PPT” | 没有点名模板时，走新建 PPT 工作流。 |
