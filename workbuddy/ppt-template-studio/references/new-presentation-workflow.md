# 无模板新建工作流

当用户没有点名模板包时，先识别本次 PPT 要帮助受众理解、决定或推动什么。只收集未能从对话推断的必要信息：内容依据、受众与目标、页数或视觉方向。

题目、受众和目的已明确时，直接给一个简短的大纲并开始制作。用户说“先确认大纲”时等待其确认；用户说“直接制作”且关键信息已齐时直接做，不回到长表单。

每页承担一个明确表达任务：封面说明主题和对象；正文页面用证据、对比、时间线、案例、产品模块或图表支撑一个观点；结尾明确结论、建议或下一步。根据业务类型选择叙事而不是强行固定页码：

| 场景 | 常用结构 |
| --- | --- |
| 市场调研 | 范围与结论、规模趋势、公司/产品、技术路线、案例、建议 |
| 管理层汇报 | 结论先行、现状、关键问题、选择、决策事项 |
| 项目复盘 | 目标、过程、结果、问题、下一步 |
| 产品方案 | 用户问题、方案、能力、场景、价值、推进计划 |

图片、图标、截图和图表须服务于页面表达：封面使用主题相关的主视觉，正文图片对应具体业务或产品事实，图标使用同一视觉体系。输出时保留可编辑文字和图表，不把全页做成一张图片。
