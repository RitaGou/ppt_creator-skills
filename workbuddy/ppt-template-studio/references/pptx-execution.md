# PPTX 执行说明

在 WorkBuddy 任务中优先使用可用的 `PPTX` 办公文档能力。开始前确认它能：读取或导入原始模板、生成可编辑 PPTX、预览或渲染页面。

有模板包时，打开 `original-template.pptx` 后优先复用母版、布局、已有页面和已记录素材槽；内容写入已记录的文本区，页面框架可变时在同一视觉体系内扩展模块。保持项不改变字体、配色、页眉页脚、页码、Logo 或指定素材。

无模板包时，根据简短大纲制作可编辑页面，并使用一致的字体、配色、图片和图标风格。封面与正文素材放在当前任务输出目录或模板包资产目录，方便后续同一模板复用。

生成后预览或渲染每页，修正文字溢出、非预期换行、图片裁切、元素对齐和页码/页眉页脚不一致，再交付 `.pptx`。
