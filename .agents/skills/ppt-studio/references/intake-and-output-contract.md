# 普通同事引导与输出约定

这份 Skill 的使用者不需要了解 Skill、Agent、母版或资产清单。先理解他们自然语言中的任务；只把缺失且会影响安全、结构或视觉结果的信息一次性问清。

## 信息完整性门槛

只有下面每项都已提供、可靠推断，或由用户明确接受默认值时，才把 `run.intake.status` 记录为 `complete` 并开始制作。任一项未知时记录 `awaiting-input`，列入 `missingRequired`，只发起补充问题；不要先写大纲、检查模板、调用 PPTX 生成、获取素材或沉淀模板。

| 必需信息 | 可以怎样满足 |
|---|---|
| 受众与希望推动的决定/行动 | 用户直接说明，或明确同意一个复述后的判断。 |
| 主题与内容依据 | 提供材料/数据及其负责人，或明确声明为虚构样例、假设或待补数据。 |
| 数据边界 | 绿色资料可继续；黄色资料还需当前处理环境已获批；红色资料停止并改要汇总、脱敏或虚构版本。 |
| 交付基线 | 语言、PPTX 格式、页数或篇幅预期、时间要求；可由用户接受的合理默认值补足。 |
| 视觉路线 | 指定并可读取的 PPTX/POTX、已批准 registry 条目、明确视觉方向，或明确同意简洁默认版式。 |
| 素材策略 | `supplied-only`、`approved-internal-only`、`bounded-default` 或 `external-approved` 中的一项。 |
| 工作方式 | 先确认逐页大纲，或在上述信息完整后直接生成。 |

“以后也要复用模板”还需要单独补齐模板所有者、可保留/分发范围和目标位置；它不是本次 PPT 可以直接开始的替代条件。

## 每轮补充与开始规则

1. 首轮只汇总 `missingRequired`，一次性询问仍缺少的项目，并回显当前路线和 `awaiting-input` 状态。
2. 用户补充后重新核对整个门槛；不要把未回答的字段当作同意，也不要用另一套默认模板静默补齐。
3. 仅在所有必需项完成、指定模板可读取且需要的环境/权利确认已经记录后，回复首次回执、建立 ghost deck，并调用 PPTX 生产能力。
4. 如果用户想把一次性模板沉淀为可复用模板，先完成当前 deck 或明确放弃它；再进行单独的保留授权与 registry 登记检查。

## 首轮一次性补充问题

只询问未提供的项目。可直接使用下面这段中文，不要求用户填写技术字段：

> 为了做成可直接使用的 PPT，请补充以下尚未说明的信息：
>
> 1. 这份 PPT 给谁看？希望他们看完后决定或行动什么？
> 2. 主题、交付日期、预计页数和语言是什么？已有的文档、数据、旧 PPT 或链接有哪些？
> 3. 资料是否含内部、客户或个人信息？如含内部资料，请确认当前处理环境已经获批；如含个人/薪酬/健康等敏感信息，请先提供汇总或脱敏版本。
> 4. 是否要复用某份 PPT 模板？请上传或给出准确路径，并说明只是本次使用，还是希望以后也复用。
> 5. 封面、产品截图、照片、Logo、图标是否有必须使用的素材或品牌规范？
> 6. 素材使用方式请选择一项：只用我给的素材；只用已批准的内部素材；可以按简洁默认方式制作；可以在已批准范围内搜索/生成素材。
> 7. 你希望先确认逐页大纲，还是在上述信息明确后直接生成？

## 首次回执

在生成前，用普通语言给出一段简短确认，而不是展示内部实现细节：

> 我会按“[业务场景/自定义目标]”制作，面向“[受众]”，重点推动“[决定/行动]”。
>
> 视觉上将采用“[用户模板/已批准模板/自定义方向/简洁默认]”，素材按“[素材策略]”处理。先给出逐页结构后再生成/信息已完整，直接生成。

内部同时记录完整路线：data class → scenario preset → template mode → asset policy → disposition。

## 三种必须暂停的回复

### 指定模板缺失

> 我还不能按你指定的模板生成，因为“[文件标识]”当前无法读取。请上传模板、修正路径，或明确允许我改用某个视觉方向；在你选择前，我不会静默换成其他模板。

### 黄色资料但环境未确认

> 这份资料属于内部/脱敏资料。请先确认当前处理环境已经获批；确认前我不会解析模板、读取来源或请求外部素材。

### 红色敏感资料

> 资料含有人事、薪酬、健康、可识别客户或其他敏感内容。我不能据此创建或联网补充 PPT 素材。请提供部门级汇总、虚构示例，或指向已批准的受控流程。

## 交付时的普通语言说明

交付时说明：PPTX 已生成；封面/图标/图片等素材放在同名 deck-assets 文件夹；如有素材可经批准复用，清单会标注可复用范围；如果有待确认的来源、授权或渲染检查，明确列出而不说“已完成”。
