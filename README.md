# PPT Creator Skills

把一份现有 PPT 沉淀为可点名复用的模板包；之后普通用户只要给出模板包名称、主题或简要内容，就能快速生成同一视觉体系下的可编辑 PPT。

## 能做什么

- 从原始 PPTX/POTX 提取版式、字体、配色、页眉页脚、页码、图片、图标、文字容量和页面模块，制作成模板包。
- 让模板包创建者按类别决定哪些内容保持、哪些可变、哪些每次使用时再问。
- 用模板包名称和内容快速生成 PPT；大框架、页数和边界都按需补充，不要求用户逐页填写字段。
- 生成可编辑 PPTX，并在生成时复用模板包的视觉基线、页面模块和素材槽。

## 快速开始

有现成 PPT 模板时，先用 `$ppt-template-pack-builder` 制作一次模板包；以后直接用 `$ppt-template-fill` 调用它。

| Skill | 适合什么情况 |
| --- | --- |
| `$ppt-template-pack-builder` | 把现有 PPTX/POTX 做成可反复调用的模板包。 |
| `$ppt-template-fill` | 已有模板包，想用主题、内容或大框架快速生成 PPT。 |
| `$ppt-studio` | 没有模板包、需要先做研究，或需要全新视觉方向的 PPT。 |

## 创建模板包

准备一份你希望复用的原始 PPTX/POTX，然后这样说：

```text
使用 $ppt-template-pack-builder 将这份 PPTX 创建为「模板包名称」模板包，并帮我确认哪些内容保持、可变或每次确认。
```

制作器会提取原件中的视觉和版式信息，并用一张确认卡让创建者确定默认大框架、五类边界、可变范围、内容/素材默认方式以及名称和版本。确认后会登记到当前工作区的模板库，日常调用不需要重复填写路径、坐标或对象属性。

## 使用模板包生成 PPT

最短调用只需模板包名称和一项内容依据：

```text
用「模板包名称」生成 PPT；内容：[主题、简要内容、提纲或材料]。
```

大框架、`页数：[N]`、字数和边界都是可选补充；未写的项目会沿用模板包默认值。只有名称/版本不明确、内容不足、边界相互矛盾或该类别被设置为“每次确认”时，Skill 才会问一个聚焦问题。

## 三种边界控制

每个类别都可以单独指定，不需要选择全局模式。

| 设置 | 含义 | 常见对象 |
| --- | --- | --- |
| 保持 | 沿用模板包中的原有设计或规则。 | 字体、配色、页眉页脚、页码、Logo。 |
| 可变 | 在模板包的视觉体系内按本次内容复用或扩展。 | 封面图、正文配图、页内模块、新增页面。 |
| 每次确认 | 本次生成前只询问这一类的一项决定。 | 页数、封面图、交付语言。 |

可控制的类别包括：视觉基线、页面框架、视觉素材、内容与数据、交付形式。比如可以同时设定“字体和页眉页脚保持，封面图可变，页数每次确认”。

## 示例

```text
使用 $ppt-template-pack-builder 将一份现有 PPTX 创建为「市场调研·活力手账」模板包，并设置：字体、配色、页眉页脚保持；封面图、正文配图和页内模块可变；页数每次确认。
```

```text
使用 $ppt-template-fill 用「市场调研·活力手账」生成 PPT。
大框架：市场趋势、产品地图、技术路线、结论建议。
内容：XR 直播间，面向内部领导。
页数：12。
边界：保留字体、配色、页眉页脚；封面图和正文配图可按主题替换；允许新增两页。
```
